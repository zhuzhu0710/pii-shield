# 個資隱身術

把文件裡的個人資料（姓名、身分證字號、手機、地址、Email、公司與統編等）找出來、隱藏起來，存成一份新的文件。需要時，再用「還原鑰匙檔」把原文換回來。

- **檔案不會離開你的電腦。** 所有處理都在瀏覽器中完成，沒有後端伺服器；載入頁面後即使離線也能使用。
- **三個步驟。** 放入檔案 → 檢查標記 → 下載。每一步都會告訴你下一步要做什麼。
- **可以還原。** 下載時附上「還原鑰匙檔」（CSV），之後到「還原」頁上傳文件與鑰匙檔，就能換回原文。
- **支援常見格式。** PDF（含掃描檔，會在瀏覽器內辨識文字）、Word（.docx）、Excel（.xlsx）、TXT、Markdown，也可以直接貼上文字。

## 使用方式

### 1. 放入檔案

把檔案拖進頁面，或點一下選擇檔案；也可以直接貼上文字。第一次使用，可以按「先用範例試試看」，範例都是虛構資料。

### 2. 檢查標記

預覽就是下載後文件的樣子。自動找出的個資會被標上顏色：

- 點一下標記，可以取消隱藏（誤判時使用）。
- 用滑鼠圈選文字，可以隱藏自動沒有找到的內容。
- 虛線框的標記表示「不太確定」，建議優先確認。
- 右側會列出這份文件找到的個資數量。

「調整輸出方式」可以設定要露出多少（露出部分、全部隱藏、自訂），以及標記的寫法。

### 3. 下載

下載時會有兩個檔案，名稱都寫得很清楚：

- **隱藏個資後的文件**：與原檔相同格式，可以交給其他人或 AI 處理。
- **還原鑰匙檔**：記錄每個標記對應的原文。**請妥善保存，不要和文件一起寄出。** 沒有它就無法還原；有它的人可以看到所有被隱藏的內容。

多個檔案可以一鍵打包成 ZIP 下載。

### 還原

到「還原」頁，上傳隱藏個資後的文件與還原鑰匙檔，就能下載還原後的文件。

也可以切換到「貼上 AI 的回覆來還原」：把隱藏後的文字交給 ChatGPT、Claude 等 AI 處理，再把它的回覆貼回來，工具會把回覆裡的標記換回原文。

### 進階設定

「進階設定」頁是給需要的人用的，一般使用不需要調整：

- 白名單（不要隱藏的詞）與黑名單（一定要隱藏的詞）。
- 停用不需要的偵測規則，或新增自訂規則（例如員工編號、案號）。

這些設定只存在你的瀏覽器中。

## 標記方式

| 標記方式 | 寫法範例 | 會產生還原鑰匙檔？ | 之後能還原？ |
| --- | --- | --- | --- |
| 可還原 | `王[姓名:6e679d]` | 會 | 能 |
| 類別標記 | `王[姓名]` | 不會 | 不能 |
| 空白佔位 | `王○○`（保留原字數） | 不會 | 不能 |

只要不需要還原，就選「類別標記」或「空白佔位」。

## 支援的個資類型

內建：中文姓名、身分證字號（含檢核碼）、手機、市話、地址、電子郵件、公司名稱、統一編號（含檢核碼），以及自訂識別碼。另有國際電話、信用卡號、美國社會安全碼、IBAN、IP 位址與出生日期。

自動找出的結果只是建議，中文姓名與地址無法做到完全正確。下載前請逐一確認。

## 限制

- 單檔上限 100 MB，一次最多 10 個檔案。
- 不支援舊版 `.doc` 與 `.xls`。
- PDF 會依原位置重建文字，圖片與原字型不會保留。
- 掃描檔的文字辨識可能有錯字，請逐頁對照原檔核對。
- 露出部分會留下部分字元，並非完全匿名。

## 自行架設

需要 [Node.js](https://nodejs.org/)（建議 22 以上）。

```bash
npm install
npm run build
```

`dist/` 資料夾就是完整的網站，可以放到內網伺服器、GitHub Pages 或任何靜態空間，也可以直接用瀏覽器開啟。

開發時：

```bash
npm run dev     # 本機開發伺服器
npm test        # 執行測試
```

### 改名字

產品名稱與標語只在 `src/brand.ts` 設定，頁面標題、標頭與下載的說明都會跟著改。

## 專案結構

- `src/core/`：偵測、遮罩、還原與編碼的核心邏輯。
- `src/formats/`：各種檔案格式的讀取與輸出（Word、Excel、PDF、OCR）。
- `src/ui/`：畫面（三個步驟、預覽、還原、進階設定）。
- `tests/`：單元與整合測試。
