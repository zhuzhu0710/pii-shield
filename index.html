__BRAND_NAME__

__BRAND_TAGLINE__。上傳 PDF、Word、Excel、TXT、Markdown 或貼上文字，自動找出姓名、身分證字號、手機、市話、地址、電子郵件、公司名稱、統一編號與自訂的識別碼，檢查後隱藏並下載，附上還原鑰匙檔，之後可以換回原文。

使用說明與常見問題

三個步驟

  1. 放入檔案：把檔案拖進來，或直接貼上文字。
  2. 檢查標記：確認自動找出的個資都已被標記。點一下標記可取消，用滑鼠圈選文字可新增。
  3. 下載：下載隱藏個資後的文件，以及還原鑰匙檔。鑰匙檔請妥善保存，不要和文件一起寄出。

需要還原時，到「還原」頁上傳文件與還原鑰匙檔，就能換回原文。

常見問題

這個工具是做什麼的？

把文件裡的姓名、身分證字號、電話、地址、Email 等個人資料找出來並隱藏，存成一份新的文件。需要時再用還原鑰匙檔，把隱藏的內容換回原文。

我的檔案會被上傳到伺服器嗎？

不會。所有處理都在你的瀏覽器內以 JavaScript 完成，沒有後端伺服器。載入頁面後即使離線也能使用。瀏覽器只會記住你在「進階設定」調整過的規則，文件內容與還原鑰匙檔都不會被保存。

支援哪些檔案格式？

支援 PDF（含掃描檔，會在瀏覽器內辨識文字）、Word（.docx）、Excel（.xlsx）、TXT、Markdown，也可以直接貼上文字。單檔上限 100 MB，一次最多 10 個檔案。不支援舊版 .doc 與 .xls。

可以找出哪些個資？

內建姓名、身分證字號（含檢核碼）、手機、市話、地址、電子郵件、公司名稱、統一編號（含檢核碼），以及自訂的員工編號、案號等。另有國際電話、信用卡號、美國社會安全碼、IBAN、IP 位址與出生日期。

什麼是還原鑰匙檔？

每個被隱藏的內容都會換成一個編號標記，例如 王[姓名:6e679d]。還原鑰匙檔是一份 CSV 檔，記錄被隱藏的原始內容，還原時需要它。鑰匙檔遺失就無法還原；拿到鑰匙檔的人可以看到所有被隱藏的內容。

不需要還原，可以只把個資遮掉嗎？

可以。在「調整輸出方式」的「標記」改選「類別標記」，會寫成 [姓名]、[手機]；或選「空白佔位」，每個字改成「○」，分隔符號保留，例如 0912-○○○-○○○。這兩種方式不會產生還原鑰匙檔，之後無法還原。

自動找出的結果一定正確嗎？

不一定。中文姓名與地址無法靠規則做到完全正確，所以自動結果只是建議。在檢查標記的步驟，點一下標記可取消誤判，用滑鼠圈選文字可補上漏掉的內容，確認後再下載。

掃描的 PDF 可以用嗎？

可以。沒有文字層的 PDF 會在瀏覽器內以 OCR 辨識繁體中文與英文，再自動找出個資。辨識可能有錯字，下載前請逐頁對照原檔核對。

這個工具要收費嗎？可以自己架設嗎？

免費，以 MIT 授權開源。執行 npm install 與 npm run build 後，dist 資料夾就是一個純靜態網站，可以放到內網伺服器或任何靜態空間，也可以直接用瀏覽器開啟。
